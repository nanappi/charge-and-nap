# Charge & Nap

전기차 충전 시간을 편안하고 안전한 파워냅으로 바꾸는 음성 중심 차량 슬립케어 서비스입니다.

> **한 문장 소개**
>
> “충전하는 동안 20분만 잘래”라고 말하면, 남은 충전 시간을 기준으로 차량 환경을 자동 조절하고 충전 완료 전에 자연스럽게 깨워줍니다.

## 해결하려는 문제

전기차 충전 대기 시간에 쉬고 싶어도 운전자가 좌석, 공조, 조명, 오디오와 알람을 각각 설정해야 합니다. 충전 완료 시점을 계속 확인해야 하고, 너무 깊게 잠들거나 충전이 끝난 뒤에도 자리를 비우지 못할 수 있다는 부담도 있습니다.

Charge & Nap은 이 과정을 한 번의 음성 명령으로 묶어, **정차·충전 중에만 작동하는 안전한 차량 휴식 경험**을 만듭니다.

## 핵심 흐름

1. 차량이 충전 중이고 안전하게 정차했는지 확인합니다.
2. 운전자가 음성으로 수면 모드를 요청합니다.
3. 남은 충전 시간에 맞춰 적절한 수면시간을 제안합니다.
4. 좌석·공조·조명·오디오를 수면 환경으로 전환합니다.
5. 충전 완료 전에 조명·음악·시트 각도를 단계적으로 복귀시켜 깨웁니다.
6. 반응이 없으면 음성과 시트 진동으로 재알림합니다.

## MVP 기능

- 충전 상태와 남은 충전시간 표시
- 음성 명령 기반 수면 모드 시작
- 좌석, 공조, 조명, 오디오 상태 변화 시뮬레이션
- 충전 완료 전 단계적 웨이크업
- 무응답 시 다중 재알림
- 주행 중 또는 충전 중이 아닐 때 실행 차단

## 안전 원칙

- 현재 MVP는 **P단·정차·충전 중**인 경우에만 활성화합니다.
- 운전자 상태를 임의로 판단해 주행 중 수면을 권하지 않습니다.
- 자율주행 확장안은 제조사가 공식적으로 수면을 허용하는 자동화 수준과 운행 조건이 검증된 이후에만 다룹니다.
- 차량 제어 실패 시 기본 차량 설정으로 안전하게 복귀합니다.

## 로컬 실행

`index.html`을 브라우저에서 열거나 간단한 정적 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

이후 `http://localhost:8000`에 접속합니다.

## 현재 상태

공모전 검증용 인터랙티브 프로토타입 단계입니다. 실제 차량 연동 전에는 Pleos SDK/에뮬레이터에서 지원 API와 권한, 안전 조건을 확인해야 합니다.
